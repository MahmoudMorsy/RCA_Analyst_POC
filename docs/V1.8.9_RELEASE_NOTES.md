# RCA Analyst v1.8.9 Release Notes

**Application:** v1.8.9  
**Embedded RCA Core:** v0.8.8 candidate  
**Base:** validated v1.8.8 package

## Why v1.8.9 exists

After v1.8.8, four controlled RunPod reruns were executed with the critical semantic roles physically resolved to Qwen3.8-27B. TEST-006 and TEST-012 became clean controls, while TEST-017 and TEST-021 isolated deterministic/core integration defects that remained even with correct semantic interpretation. Two Web UX defects were also confirmed during live execution: reconnecting a browser did not rediscover a still-running backend run, and live polling repeatedly collapsed expanded pipeline objects.

v1.8.9 fixes those systemic defects without testcase-specific logic and without weakening the frozen evidence model.

## RCA Core v0.8.8

- VERIFIED semantic facts are reusable across any structurally matching Requirement IR; `related_requirement_ids` is no longer an execution whitelist.
- Targeted structural completion is all-target: every requested field must be returned or the patch is rejected.
- Semantic arbitration is field-atomic and non-regressive. Existing Requirement IRs are patched only in Python-approved fields.
- Legacy full arbitration IRs are backward compatible, but only approved target fields are copied.
- Free-form `unresolved_case_semantics` is advisory unless represented by a concrete structured material issue.
- Canonical evidence class/source is authoritative for diagnostic and historical RCA packet routing.
- Materially unresolved requirements remain visible to RCA as unresolved normative context.
- Strict RCA provenance validates machine ID fields while allowing human-readable `source_references` labels.

## Web application v1.8.9

### Active-run rediscovery after browser reconnect

After successful backend authentication, the browser queries `/runs` and reconciles non-terminal `QUEUED`, `INITIALIZING`, `RUNNING` and `CANCELLING` runs. A single active run is resumed automatically. Multiple active runs are exposed in an Active Runs selector. Browser `localStorage` is a hint, not the source of truth.

Closing/reopening the Web page no longer detaches the user from a backend run that is still executing. This does not fake-resume an analysis after a backend process restart; interrupted backend work remains an interrupted/failed run with preserved artifacts.

### Live pipeline interaction state

Structured Input/Output trees now use stable semantic paths and retain expanded/collapsed nodes across polling rerenders. Expansion state is scoped by backend profile, run, testcase, stage and view. Selected testcase/stage are persisted per run, and live rerenders retain the user’s inspection position rather than forcing repeated collapse.

## Controlled 27B evidence that drove this release

- TEST-006: correct PROHIBITIVE semantics and deterministic VIOLATED / NOT APPLICABLE outcome with no material semantic blocker.
- TEST-012: correct REQ-1204 timing violation at 1100 ms vs 800 ms, REQ-1202/1206 NOT APPLICABLE, REQ-1207 SATISFIED.
- TEST-017: compiler/verifier semantics were correct; failure was deterministic fact reuse across requirements.
- TEST-021: exposed all-target structural-completion, atomic arbitration, diagnostic/history packet routing and hypothesis provenance integration defects.

## Automated regression gates

v1.8.9 adds regressions for:

1. cross-requirement reuse of VERIFIED facts;
2. TEST-017 deterministic outcome with restricted semantic linkage metadata;
3. rejection of partial structural patches;
4. atomic arbitration non-regression;
5. advisory case-level free-text ambiguity;
6. canonical diagnostic/history packet classification;
7. display source references vs machine evidence IDs;
8. unresolved requirement visibility in RCA;
9. active-run reconnect and pipeline tree-state Web contracts.

The release suite contains **225 tests**.

## Candidate status

RCA Core v0.8.8 remains a candidate until the exact v1.8.9 package passes a stable live full-suite run with the intended 27B critical-semantic topology. TC17 and TC12 remain explicit semantic anchors; TC21 is the RCA integration anchor for this release.
