# RCA Analyst v1.8.4 Release Notes

## Release type

Major **application architecture/deployment** refactor. RCA Core semantic baseline remains v0.8.4.

## Added

- modern browser UI with complete desktop-control/result migration surface;
- saved Local Dell / RunPod / Home AI Server / Custom backend profiles;
- backend connection/health/version/hardware/model/capability display;
- fixed FastAPI `/api/v1` contract;
- asynchronous persistent run IDs and explicit run states;
- disconnect/reconnect-safe run inspection;
- remote Stop/Abort and cooperative model-request cancellation;
- structured dynamic pipeline API and SSE replay;
- provider-neutral ModelClient/ModelGateway boundary;
- primary/small independent model endpoints/providers;
- RCA vs inference-engine vs infrastructure configuration separation;
- capability-gated engine controls;
- backend-managed file upload/download;
- storage abstraction/configurable root;
- run history/benchmark data;
- system/GPU telemetry where available;
- session envelope schema v2 with legacy desktop migration and original-payload retention;
- bearer authentication/CORS controls for remote deployments;
- Local Dell, RunPod and Home AI Server deployment profiles/guides;
- Dockerfile/docker-compose startup path;
- frozen desktop fallback via `run_desktop.py` / `run_desktop.bat`;
- mandatory Desktop UI → Web/API migration matrix.

## Preserved

The v0.8.4 RCA semantic compiler, evidence semantics, deterministic compliance, timing, arbitration, RCA routing, repairs, validation, formatting and TC regression expectations are not redesigned in this release.

## Testing

The original 175 tests remain and pass. v1.8.4 adds web/backend migration tests for API health/config, async jobs, reconnect, cancellation, provider failure, files, report/session downloads, legacy session migration, run history/telemetry, unsupported engine settings, capability discovery, remote auth, deployment profiles, ModelGateway decoupling and SSE event replay.

Live TC12/TC17 model validation remains required before freezing v1.8.4 as the semantic production baseline.
