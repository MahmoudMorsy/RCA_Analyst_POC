# v0.5.5 release notes

## Scope

v0.5.5 is a focused observability and evidence-plan correction release on top of v0.5.4. It does not change the frozen state/transition/interval semantic baseline.

## Corrections

- Minimum-next-evidence clock alignment is now evidence-driven. A same-clock trigger/response pair does not produce a timebase request merely because other prose contains words such as `aligned`.
- Different clocks/sources still produce an explicit alignment acquisition need when current evidence demonstrates that alignment is actually required.

## Live Pipeline tab

The GUI now shows the real pipeline from raw user input through final report. Stages are emitted during execution, not reconstructed afterward. Each stage exposes a concise overview plus exact input and output panes. Long-running LLM stages show their input immediately and update their output when the call completes. Sequential batch runs reuse the same inspector for the currently active case.
