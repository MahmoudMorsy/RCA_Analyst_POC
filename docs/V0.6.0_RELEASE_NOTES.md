# v0.6.0 release notes

v0.6.0 introduces the multi-model RCA architecture. It is a minor-version release because responsibility is deliberately redistributed across Qwen3.5-4B, Qwen3.8-27B, and deterministic Python while the frozen evidence semantics remain unchanged.

## Architecture

- **Qwen3.5-4B intake normalizer:** used conditionally for inconsistent human testcase formatting. It extracts source-backed sections but is not allowed to invent evidence semantics.
- **Python canonicalizer:** verifies cited source spans, assigns evidence IDs/classes/provenance, and deterministically parses raw trace text. Trace transitions, timestamps, clocks and event-completeness semantics remain Python-owned.
- **Qwen3.8-27B primary:** remains responsible for deep requirement/evidence/RCA semantic reasoning.
- **Tiered repair:** deterministic Python first, Qwen3.5-4B narrow field patch second, Qwen3.8-27B semantic escalation/fallback where required.
- **Qwen3.5-4B final review:** checks wording against a compact authoritative fact set and may propose `relevance` patches only.
- **Python final gate:** revalidates any review patch and always performs the final deterministic validation before formatting.

## TC5 evidence-plan correction

For a timed response where trigger and observed response timestamps already exist on the same clock but complete transition-event coverage is absent, v0.6.0 now states the known timing facts and requests only complete transition-event coverage needed to exclude an earlier omitted response transition. It does not re-request timestamps or a timebase.

## Observability

The Live Pipeline tab now reflects the expanded runtime path: raw input, input classification, optional 4B intake, Python canonicalization, 27B primary analysis, deterministic validation, repairs, final semantic validation, optional 4B final review, Python final gate, deterministic report formatting and final output.

## Verification

The offline suite contains 104 automated tests, including guards for source-backed intake, deterministic transition ownership, final-review authority containment, TC5 timing wording/evidence precision, frozen TC1-TC3 semantics, v0.5.3-v0.5.5 result-driven regressions, structured-output recovery, and semantic batch acceptance.
