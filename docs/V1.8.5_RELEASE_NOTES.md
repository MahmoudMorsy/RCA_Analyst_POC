# RCA Analyst v1.8.5 Release Notes

## Purpose

v1.8.5 is a maintenance release of the v1.8.4 Web/backend refactor. It fixes backend startup on the existing Dell Python 3.9 environment.

## Fixed

FastAPI/Pydantic evaluates dependency and endpoint annotations at runtime. v1.8.4 used PEP 604 optional annotations (`T | None`) in `rca_server`, which fail when evaluated by Python 3.9. v1.8.5 replaces those server-layer annotations with `typing.Optional[T]`.

## RCA semantics

No RCA reasoning, evidence, compliance, repair, timing, semantic IR, validation or reporting behavior changed. The RCA semantic baseline remains v0.8.4.

## Regression protection

Python 3.9 compatibility scanning now covers both `rca_app` and `rca_server`, and the backend app import/startup path is explicitly tested.
