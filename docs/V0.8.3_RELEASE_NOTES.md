# RCA Analyst POC v0.8.3 — Release Notes

## Purpose

**Live-TC12 compiler-transport hardening.** v0.8.3 keeps the v0.8 semantic-compiler / deterministic-compliance architecture and fixes a failure exposed by the TC12 v0.8.2 live run.

## Live TC12 v0.8.2 finding

The v0.8.2 run failed before semantic verification or arbitration because the fast semantic compiler returned Requirement IR predicates that were semantically understandable but structurally incomplete.

Examples from the live output included:

- `source_phrase = "ActiveVariant is MANUAL"`, `operator = EQ`, `value = MANUAL`, but no `signal` field;
- `source_phrase = "VehicleSpeed is above 0"`, `operator = GT`, `value = 0`, but no `signal` field;
- similar missing predicate signals for POWER-variant and ChildLock conditions.

Both bounded model attempts completed normally with `finish_reason=stop`. The failure was therefore not token truncation. It was a schema-contract mismatch: the generated JSON satisfied the exposed transport schema closely enough to be useful, but a hidden Pydantic cross-field validator rejected the entire RequirementCompilationBatch because `PREDICATE.signal` was empty.

The deterministic TC12 timestamp fix remains correct in the failed session: `99.900`, `100.000`, `100.600`, and `101.100` are preserved with the correct transition metadata.

## Changes

### 1. Separate transport-valid IR from executable IR

`LogicExpression` no longer aborts model transport merely because an AST node is structurally incomplete.

A partial model response can now be retained long enough for the semantic integrity / repair pipeline to inspect it. This does **not** make the partial IR executable.

Python still does not reconstruct missing requirement meaning from natural language.

### 2. Explicit structural Requirement IR checks

`SemanticIntegrityChecker` now detects transport-level defects such as:

- PREDICATE without `signal`;
- PREDICATE without an executable operator;
- malformed PREDICATE child structure;
- malformed NOT / AND / OR / TRUE node shape;
- trigger object without signal/event;
- required behavior without signal/process description;
- timing object without `limit_ms`.

All such defects are material and block deterministic compliance execution.

### 3. One bounded cheap 4B structural-completion pass

Before the independent requirement-vs-IR semantic verifier and before any 27B arbitration, v0.8.3 performs at most one targeted 4B recompilation for requirements containing structural IR defects.

The repair call:

- receives the original requirement text;
- receives the exact structural defect list;
- recompiles only affected requirements;
- does not ask Python to infer the missing signal or logic;
- does not consume a 27B call.

If the fast structural-completion call fails or remains incomplete, the normal semantic-verification / single 27B arbitration path remains authoritative.

### 4. Stronger compiler prompt contract

The fast semantic compiler now states explicitly that every `PREDICATE` node must contain:

- `signal`;
- `operator`;
- `value`.

A `source_phrase` or `semantic_id` does not substitute for the actual executable fields.

### 5. Arbitration remains strict

The transport model is more tolerant, but the 27B arbitration replacement contract is **not** relaxed.

A Requirement IR returned as an arbitration repair is rejected if a PREDICATE still lacks `signal`, lacks an executable operator, or has malformed Boolean structure. Arbitration must return an executable replacement or leave the issue explicitly unresolved.

## Expected TC12 behavior

The unchanged TC12 target remains:

- REQ-1201: APPLICABLE / NOT EVALUABLE;
- REQ-1202: NOT APPLICABLE;
- REQ-1203: APPLICABILITY UNKNOWN / NOT EVALUABLE;
- REQ-1204: APPLICABLE / VIOLATED, deterministic 1100 ms vs 800 ms, +300 ms;
- REQ-1205: APPLICABILITY UNKNOWN / NOT EVALUABLE;
- REQ-1206: NOT APPLICABLE;
- REQ-1207: APPLICABLE / SATISFIED;
- REQ-1208: APPLICABILITY UNKNOWN / NOT EVALUABLE;
- REQ-1209: APPLICABILITY UNKNOWN / NOT EVALUABLE;
- REQ-1210: APPLICABILITY UNKNOWN / NOT EVALUABLE;
- no unsupported mechanism hypothesis.

A missing compiler transport field must no longer abort the case. It should be repaired by the bounded 4B structural-completion pass when possible, otherwise escalated conservatively through the existing semantic arbitration boundary.
