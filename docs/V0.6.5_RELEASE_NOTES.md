# RCA Analyst POC v0.6.5 — Hypothesis Safety + Non-Thinking Final Review

v0.6.5 is a focused correction release based on the real TC5 v0.6.4 run.

## Final 4B reviewer execution

The structured review contract from v0.6.4 is retained. The default execution is changed back to:

- reasoning: `provider_default`
- Thinking: `off`
- transport: `auto` (Qwen3.5 resolves to `qwen35-manual`)

The v0.6.4 TC5 run showed that Low-thinking OpenAI-chat review consumed the complete output budget in reasoning, retried, and still returned empty assistant content. If a user explicitly enables chat/thinking in v0.6.5 and the structured output is exhausted/empty, one bounded manual non-thinking recovery is attempted. Network failures are not duplicated.

## Hypothesis safety

A timing requirement that remains `NOT EVALUABLE` because complete transition-event coverage is missing cannot be converted into a supported hypothesis using only the same mapped trigger/response observations already declared insufficient. This prevents TC5 from reporting “the actual response is delayed beyond 500 ms” while simultaneously saying the first response transition cannot be established. Independent mechanism evidence can still support a candidate hypothesis.
