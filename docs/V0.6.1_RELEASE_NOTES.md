# v0.6.1 release notes

v0.6.1 adds user-driven cancellation without changing the frozen RCA evidence semantics.

## Stop behavior

- A visible **Stop** button is enabled only while a single-case or batch worker is active.
- Stop sets a shared `CancellationToken` consumed by `RCAPipeline` and every LM Studio client role.
- GUI inference requests are streamed; when Stop is requested the active response is closed and any partial JSON/reasoning is discarded.
- Python stages check cancellation between pipeline boundaries and repair actions.
- Single-case cancellation emits no final RCA report and disables report/session export for the aborted run.
- Batch cancellation preserves completed case artifacts, aborts the active case, and does not start remaining queued cases.
- The Live Pipeline marks the interrupted running stage as `CANCELLED`.

## Verification

107 automated tests pass, including explicit guards that partial streamed JSON is rejected and pre-cancelled pipelines never call the primary model.
